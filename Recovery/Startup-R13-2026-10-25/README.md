## What actually needed recovery

Two managed bodies had collapsed to warning/pop/return-zero stubs. Original GetDevicePlaceCD is a bounded unsigned (id-4) switch: IDs 4 ->20, 5 ->3, 6/9 ->60, 10/14 ->120, all others ->positive float zero. Original BoardEntry.GetValue has a 36-entry selector map and ten branch groups. It returns per-type/per-level constants (including signed negative and fractional values), plus one float32(level)*10 group. These are complete body reconstructions, not integer-zero-to-float substitutions. Both original jump tables are decoded, their guards/selector bytes retained, and every level branch is symbolically partitioned by original Int32 equality tests. All nonconstant partitions are proved to return zero except the explicit level*10 formula. Original partial direct CFG dumps remain in the archive; use the expanded table CFGs for these two functions.

Swf rate setters restore positive float zero for native ordered clamp comparisons and field writes. Negative zero is preserved on the unchanged path; NaN follows the native ordered-comparison behavior. FrameRate restores a float-zero result for a null/destroyed Unity clip and preserves the native clip reload after the truthiness call. StatsIncreased restores a float zero and uses the value captured after the multi test, matching the original single field read.

DamageText captures animator immediately after the first timeScale call and captures speed-hash before the second timeScale call. The zero path calls timeScale once and sets positive float zero; NaN takes the nonzero path, which calls timeScale twice and sets float32(1/secondTimeScale). This matches original pointer/hash register lifetime under callbacks. Instance null throws follow the native guard rather than returning default values.

Zombie.GetTOU originally selects armor1/armor2 or zero, obtains Buff.GetIncrement, adds in float32, applies a custom original round routine, then Max(result,0). The decompiled CIL had lost the round entirely. Native rounding uses double fractional comparison for exact +/-0.5 ties and signed-integer parity, but otherwise adds/subtracts 0.5 in float32 before native floor/ceil. It differs from ideal MathF.Round near half values: a real physical replacement with MathF.Round produces 38 differing records. The restored CIL preserves float32 adjustment, guarded tie parity and final native Max semantics. Appended local types are Double/Single; Int64 conversion occurs only on an exact fractional-half path where the float's integer part is safely representable. No new game helper MethodDef is added.
