## 全量检测仍需要哪些运行层

1. **真实 Unity 资产/场景检查**：对固定候选重新扫描所有场景、预制体、丢失脚本和序列化引用、资源路径与 Shader/材质绑定；旧 R8 Editor 结果不能代替当前 R19。
2. **真实场景流程测试**：启动到主菜单，进入关卡，选卡、种植、出怪、攻击、掉落物、暂停/变速、胜负结算、保存/加载、退出重入。记录每条路线实际覆盖的方法、异常和日志，未到达保持未覆盖。
3. **完整 iOS 构建与打包**：对同一输入完成 Unity 导出、Apple 编译、运行时/Objective-C、链接及未签名 IPA 包结构检查。目前只有生成源码预检查通过。
4. **iPad 验收**：检查黑屏、闪烁、声音、触控与持续运行，并用设备日志判断根因。Windows CLR 和 Linux/Mac 编译不能替代 Metal/设备运行。

扫描器能够全覆盖方法清单，但运行测试只能证明已执行的输入和路径；外部 Unity、虚调用、反射、序列化事件、存档状态和设备交互不能由一次静态扫描穷尽。内部调用图只解析直接 MethodDef/MethodSpec 边，12,035 个外部/MemberRef 调用点明确没有在该图中完整解析，不把它们当作不存在。
