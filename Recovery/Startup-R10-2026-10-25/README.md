## Original source and behavior

The original PC caller at `0x180352B10` contains 592 normal-CFG instructions, including the original 49-instruction Math.Floor helper at `0x1802CC8D0`. It computes health / (maxHealth / 3), floors the float ratio as double, converts with CVTTSD2SI, clamps the resulting signed integer to 0..2, derives frame 2-clamped, compares/writes parameter_ints[0], then changes eight named body/shield/cape/helmet sprites. Invalid PC conversion returns Int32.MinValue. The CIL now checks ordered range [-2147483648,2147483648) before conv.i4 and explicitly supplies the PC invalid result for NaN/Infinity/out-of-range values. This avoids relying on unspecified invalid conversion behavior on ARM64.

Actual execution exposed two additional defects beyond the type error. A stale clamp boolean suppressed all middle-state sprite calls. The method also loaded animationSprites after the sprite getter, where native captures it before the callee. The final candidate restores frameMinusOne == 0 dispatch and captures animationSprites in existing V13 before each of 21 direct sprite reads; the remaining shared getter already had the correct capture. Original method/field/string operands, sprite indices and existing control-flow order remain, except those specified corrections and inserted conversion guard.
